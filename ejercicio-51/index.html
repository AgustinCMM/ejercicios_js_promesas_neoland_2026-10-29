Ejercicio 51 "Protocolo de Autodestrucción del Reactor"

Consigna

Único Tip: Recuerda NO escribir varias líneas de código (ni resolver todo de golpe) antes de probar cada pequeño paso. Haz una cosa, pon un console.log, pruébalo y, solo si funciona y hace lo que esperas, pasa a la siguiente. Divide y vencerás.

Variables de entrada (Estado inicial del sistema):

JavaScript

let temperaturaCore = 1000;
let barrasDeControl = ["fallo", "fallo", "ok", "fallo", "fallo"];
let energiaAuxiliar = false;
let tiempoLimite = 3000; // Tienes exactamente 3 segundos.

Objetivo: Debes construir una función llamada async function protocoloRescate() que interactúe con las variables de entrada respetando estrictamente las siguientes leyes físicas del reactor:

  1. Enfriamiento: La temperatura del núcleo solo puede descender 100 grados cada 200ms de forma continua. Se considera "estable" únicamente cuando llega a 500 o menos.
  2. Inserción de Barras: No puedes probar todas las barras al mismo tiempo. Debes intentar insertarlas secuencialmente (una por una). El mecanismo tarda 300ms en probar cada barra. En el instante en que encuentres la que dice "ok", debes detener la búsqueda.
  3. Energía: Solo cuando la temperatura sea estable y la barra correcta esté insertada, puedes encender la energiaAuxiliar (pasarla a true). Este proceso de encendido tarda exactamente 1000ms.

Output Esperado:

  • Si lo logras a tiempo: Si consigues completar toda la secuencia de rescate antes de que se acabe el tiempoLimite, la función debe resolverse retornando exactamente este string: "🌍 Protocolo completado. El mundo está a salvo."
  • Si el tiempo se agota: Si el reloj de la planta alcanza los 3000ms y tu código aún está enfriando, probando barras o encendiendo la energía, la función debe ser rechazada inmediatamente (cayendo en un .catch()) devolviendo el string: "💥 KABOOM: El reactor ha explotado".
